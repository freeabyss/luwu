# 01_global/ — 通用知识

本目录存放跨项目复用的通用知识，Agent 在相关阶段按需加载。

## 放什么

- 编码红线与命名/格式规范
- 架构设计原则、分层约定、技术选型标准
- 业务/领域术语表
- API 设计约定、统一返回结构、错误码规范
- 数据库/缓存/事务规范
- 经过提炼的经验教训与避坑指南

## 怎么放

1. 一个主题一个 Markdown 文件（可分子目录），写清结论与约束，不写流水账。
2. 在知识库根的 `../index.md`「通用知识」表登记一行，写明：
   - 本目录内的相对路径
   - 作用（一句话）
   - 适用场景/阶段（用 flow 阶段编号 ⓪–⑨ 或场景关键词，如「⑥开发、⑥代码审查」）
3. Agent 只读 index.md 中命中当前任务的条目，未登记的文件不会被加载。

## 不存什么

- 过程文档、会议纪要、任务拆解、测试报告（这些归各项目 `docs/`）
- 某项目专属的业务细节（归该项目文档，不进全局知识库）
- 基础语法常识、可从代码直接看出的东西

完整加载规则见插件内 `skills/flow/references/knowledge-base-loading.md`。
