# PRD 模板集

> ⚠️ 模板是**检查清单**，不是填空题。按实际需求保留相关章节，不涉及的直接省略。
> 小型需求（单个功能点、Bug 修复）可只用主文档 README.md，不拆子文档。

---

## 主文档模板：`docs/prd/README.md`

```markdown
# {项目/功能名称} PRD

## 文档信息

| 项 | 内容 |
|----|------|
| 版本 | v1.0 |
| 状态 | 草稿 / 评审中 / 已确认 |
| 创建日期 | YYYY-MM-DD |
| 最后更新 | YYYY-MM-DD |
| 作者 | |

## 1. 背景与目标

### 1.1 背景
{解决什么问题，当前痛点，业务上下文}

### 1.2 目标
{成功后用户/业务获得什么，量化指标优先}

### 1.3 非目标（Out of Scope）
{明确不做什么，避免范围蔓延}

## 2. 范围总览

### 2.1 核心功能清单

| 编号 | 功能模块 | 优先级 | 状态 | 详情链接 |
|------|---------|--------|------|---------|
| F01 | {模块名} | P0 | 待开发 | [features.md#F01](features.md) |
| F02 | {模块名} | P1 | 待开发 | [features.md#F02](features.md) |

### 2.2 用户角色

| 角色 | 描述 |
|------|------|
| {角色名} | {职责和权限} |

## 3. 核心流程概览

{用 Mermaid 流程图或文字描述端到端核心业务流程，复杂流程引用 user-stories.md}

## 4. 非功能需求摘要

| 类别 | 要求 |
|------|------|
| 性能 | {响应时间、并发量等} |
| 安全 | {鉴权、数据保护、合规} |
| 可用性 | {SLA、容灾、降级策略} |
| 兼容性 | {浏览器/设备/版本} |

{详细非功能需求见 non-functional.md}

## 5. UI/UX 设计规范摘要

{简述整体风格定位，详细设计规范见 ui-ux.md}

{详细风险分析见 risks.md}
```
