# PRD 模板集

> ⚠️ 模板是**检查清单**，不是填空题。按实际需求保留相关章节，不涉及的直接省略。
> 每个功能需求**必须独立成子文档**（`features/Fxx-*.md`）；术语表独立为 `glossary.md`。

---

## 目录结构

```
docs/prd/
├── README.md                       # 主文档（必建）：产品概述、用户分析、产品设计、权限、指标、发布、验收
├── glossary.md                     # 术语表（有术语时必建）
├── features/
│   ├── F01-{功能名称}.md            # 每个功能一个子文档（必建，至少一个）
│   └── F02-{功能名称}.md
├── prototype.md                    # UI/UX 设计规范 + 全局页面导航（涉及 UI 时创建）
├── user-stories.md                 # 复杂用户故事/用例/时序图（角色或流程复杂时创建）
├── non-functional.md               # 非功能需求详情（较多或复杂时创建）
├── data-model.md                   # 数据模型、ER 图、状态机（涉及数据设计时创建）
└── risks.md                        # 资损/技术风险与外部依赖（涉及资损或风险较多时创建）
```
